基于 **Python + pygame** 的回合制现代联合作战推演。地图为 n×n 方块战场，每格承载海拔、地形、
设施与控制状态；玩家部署陆、海、空、天不同武器系统，通过**侦察—决策—打击**链条达成作战目标。

核心不是"数值互砍"，而是还原现代战争的信息维度：**看不见就打不着，看得见也未必打得中，
打得中也未必穿得透；打掉了对方的天基资产，精确制导也会跟着失准。**

> 📖 **完整游戏指南见 [`GAME_GUIDE.md`](GAME_GUIDE.md)** —— 含逐条公式、预设兵器一览、
> 编辑器操作、数据格式、战术建议与自检工具。本文档只做概要。

## 快速开始

```bash
pip install pygame-ce          # 或 pip install pygame
python main.py
```

**第一次玩？** 主菜单点「**快速上手**」（或按 `T`）进入教学想定，6 步带你在 3~5 分钟内
走完一遍核心循环：认识战场 → 发现识别 → 跟踪开火 → 对手视角 → 构筑工事 → 结束回合。

其他运行方式：

```bash
python main.py --check         # 校验全部地图与武器库数据
python main.py --sim 16        # 无界面双 AI 推演 16 回合（平衡性测试）
python main.py --sim 16 --map 1
python tools/diag.py           # 作战逻辑自检（13 条不变量，含存档往返）
```

环境：Python 3.9+ / pygame 2.5+。窗口可自由缩放（最小 1180×740）。

## 作战机制

### 1. 侦察—打击链（Kill Chain）

目标必须被己方传感器探测到相应等级，才能被武器攻击：

| 等级 | 含义 | 可用性 |
|---|---|---|
| 未发现 | 完全未知 | 不可攻击 |
| 接触 | 仅知道该格有目标 | 不可攻击 |
| 识别 | 知道兵种与阵营 | 面积火力（火炮/火箭炮）可压制 |
| 跟踪 | 可装订射击诸元 | 精确制导武器可攻击 |

探测距离由多项因素相乘决定：

```
有效距离 = 传感器基础距离
         × 高度/地形优势（雷达视距）
         × (1 − 目标隐身 × (1 − 反隐身能力))
         × 目标高度层系数（低空突防 0.62 / 中空 0.85 / 高空 1.18）
         × 目标地形遮蔽（城区 0.6 / 山地 0.65 / 平原 1.0）
         × (1 − 电子干扰强度 × 0.85)
```

并且需要通过**视线（LOS）判定**：沿射线插值视线高度，与途经地块海拔比较，山地/城区/林地
会构成遮蔽。空中平台居高临下，不受地形遮蔽限制。

### 2. 电子战

- **干扰机**在半径内削弱敌方雷达探测距离与雷达/卫星制导武器命中率（最高 −85% / −55%）。
- 干扰同时降低对方**卫星导航完整性**，使 GPS/惯导弹药精度下降。
- **反辐射导弹**只能攻击正在辐射的目标。雷达关机可保命，但会失去态势感知——这是本作最核心的取舍。

### 3. 防空与拦截（逐发结算）

来袭弹药在末端遭遇防守方防空网拦截，多重拦截按独立事件取并集：

```
P_拦截 = 1 − Π(1 − Pk_i)
Pk_i  = 拦截弹基础 Pk × (1 − 弹药突防能力) × (1 − 干扰 × 0.6)
```

- 被攻击单位可自卫拦截，但火控被占用，效率 ×0.6。
- **高超音速弹药**（Kh-47M2）突防系数 0.85，现役防空系统几乎无法拦截。
- 隐身防区外弹药（JASSM）突防系数 0.45。

### 4. 防区外打击与飞行时间

射程 3 格以上的弹药会进入**在飞状态**，标注剩余回合数。抵达时重新解算：

- 目标已机动出射程 → 脱靶
- 目标已失去跟踪（传感器被摧毁/干扰）→ 命中率大幅下降
- 目标已被击毁 → 弹药自毁

### 5. 步兵、掩体与野战工事

- 步兵目标小、易隐蔽（`is_infantry`），对**面杀伤**（火炮/火箭炮/航弹）承受 +30% 伤害，
  对**直瞄火力**（坦克炮/反坦克导弹）只承受 68%——用坦克炮去打散兵是低效的。
- 城区作战中步兵伤害再降 22%，而机械化部队反而 +12%（受困于街道与废墟）。
- **掩体**：地面部队停留不动即逐回合获得掩体等级（步兵可到 Ⅱ 级，车辆 Ⅰ 级），
  提供额外减伤并压缩被探测距离；一旦机动立即归零。
- **野战工事**（地块 0–3 级）：步兵/工兵消耗 1 点机动主动构筑，工兵一次 +2 级。
  归属方获得每级 +5% 减伤与 −7% 被发现概率；敌方陆上单位进入时每级多耗 0.55 机动点
  并触发雷场伤害。面杀伤武器与火箭筒可摧毁工事，驻守工兵可修复，无人维护则逐级荒废。

### 6. 航空兵特性

- **一击坠毁**：战斗机、无人机等被任何弹药命中即空中解体（`one_shot_kill`）。
  轰炸机、预警机结构冗余，改为承受 2.2 倍伤害，通常也会被重创。
- **单回合多次发射**：战机按挂架数量可在一回合内发射多枚（F-15E / Su-35 / Su-34 为 3 次，
  F-35 / Tu-22M3 为 2 次），每次独立选择目标与武器。
- **母基地约束**：每回合消耗燃油，须返回完好机场（或航母）加油挂弹；
  AI 会按剩余航程动态计算返场时机。机场停机坪可同时停驻 4 架。

### 7. 信火一体（协同交战）

目标由友邻雷达、预警机或舰艇提供跟踪诸元时，即使本平台自身未锁定也可发射：

- 具备**数据链**（`datalink`）的平台无惩罚——即"A 射 B 导"；
- 无数据链的老式装备（步兵、老式坦克）命中率 ×0.78；
- 交战面板会显示 `信火一体：己方传感器网（协同交战）` 之类的提示。

### 8. 电子诱饵与假目标

电子战单位与舰艇可释放**诱饵**（`decoy_charges`），在敌方态势图上生成一个假目标：

- **频段差异**：雷达诱饵只在雷达/电子侦察上可见（1.30/1.45 倍距离），红外诱饵只在
  热像与部分光学上可见（1.25/0.55），目视假目标只骗光学。用错传感器就什么也看不到。
- **海陆空差异**：陆上单位放假地面目标（4 格内、存活 3 回合），舰艇放水面假目标
  （5 格内水域、4 回合），航空兵放空射诱饵（8 格内任意位置、2 回合）。
- 雷达诱饵模拟辐射源，可诱骗反辐射导弹；攻击诱饵会浪费整次射击。
- 玩家在单位面板选择「雷诱 / 红诱 / 假目标」后点地图投放；AI 会按敌方传感器构成选频段。

### 9. 弹道导弹与中段反导

- 弹道导弹（伊斯坎德尔、东风-26、匕首）**末段不可拦截**（区域防空 Pk ×0.30、近防炮 ×0.05），
  但在飞行中段可被 **SM-3 Block IIA / THAAD / 77N6-N** 交战（单发 Pk = 武器 Pk ×0.55）。
- **东风-41 洲际弹**只有中段反导一条路，战术防空网完全无效。
- 中段窗口在弹药飞行途中结算，反导弹消耗备弹；交战面板对洲际弹只显示中段估算。

### 10. 烟幕

- 火炮与火箭炮可对**任意已知坐标**施放烟幕（打的是地形，不需要目标情报），持续 3 回合。
- 该格上目标的**光电/热像/半主动制导与直瞄火力**命中 ×0.55，**探测距离 ×0.35**。
- 不影响卫星制导、惯性制导与面压制火力。AI 会在要点受威胁时自动施放。

### 11. 卫星轨道与过顶窗口

- 卫星沿地面轨迹运行（每回合东 5 / 南 3 格），**只有星下点进入战区时才有侦察窗口**。
- 过顶时覆盖星下点 14 格半径：7 格内可达跟踪级，其余识别级；「战役态势」页显示"过顶中 / 轨道外"。
- 卫星不再是全知全能的侦察网，关键时刻要靠预警机与雷达。

### 12. 航空兵任务剖面

- 打击（默认）/ 制空巡逻（雷达与空空弹 +15%，油耗 ×1.3）/ 转场（油耗 ×0.5、机动 +25%、**禁止射击**）。
- 单位面板「剖面」按钮切换，AI 会按任务自动选择。

### 13. 天基系统与反卫星作战

- 侦察卫星每 **3 回合**过顶一次，全图揭示敌方目标（识别级）。
- 卫星导航完整性随敌方电子战力量下降，直接影响 JDAM/PrSM/伊斯坎德尔等弹药精度。
- **卫星可被击落**：具备反卫星能力的平台（SM-3 Block IIA、77N6-N、THAAD 拦截弹）可对敌方
  在轨资产实施直接上升式打击。轨道目标由空间监视网编目，因此始终可被锁定，不受地形与距离限制。
- 卫星损失后：过顶侦察中断、卫星导航完整性 −30%（仅靠惯导），精确制导弹药命中率同步下降。

> 反卫星是"高风险高回报"的一次性手段：每方通常只有 1 发拦截弹，命中概率约 25%。
> 击落对方卫星能显著削弱其精确打击能力，但也会把自己的太空资产暴露在报复之下。

### 14. 基地与后勤

- **机场/港口/后勤枢纽**是有结构完整度的实体：受到打击会损毁，低于 25% 即**失能**。
- 航空兵每回合消耗 15% 燃油，返场后自动补满燃油与备弹，并逐步修复战损（每回合 +12% 结构）。
- 地面部队在后勤枢纽/机场/指挥部补充弹药（每回合 +1 发/武器）并修复战损（+7%）。
- 舰艇在港口补充弹药（每回合 +2 发/武器）并修复（+7%）。
- 设施在无敌情时由工兵自动抢修（每回合 +6%），因此压制机场需要持续打击。
- 可占领单位站上敌方设施即夺取其控制权，对方航空兵随即失去该基地保障。

### 15. 设施打击与齐射

- **设施打击**：选中单位后点击敌方机场/港口等设施即可实施结构打击；命中降低结构完整度，
  瘫痪对方补给与出动能力，同时设施周边防空网会进行拦截。
- **齐射**：交战面板可选择 1–3 发齐射。多发独立判定、命中概率取并集
  （`1−(1−Pk)^n`），但成倍消耗备弹。适合"确保关键一击"，也意味着后续火力储备下降。

### 16. 地形与机动

- 机动点按地形消耗：平原 1.0 / 林地 2.0 / 丘陵 2.0 / 山地 3.5 / 城区 1.5，爬升 400m 以上额外 +1.0。
- 友军之间可**借道通过**但不可同格堆叠。
- **两栖单位**可越过海域实施登陆（涉水消耗 2.4/格），用于夺取岛屿要点。
- 水面舰艇可占领海上目标点（海域控制）。

### 17. 回合流程

```
蓝方行动 → 结算在飞弹药 → 红方行动 → 结算在飞弹药
        → 回合推进：后勤补给 · 探测刷新 · 卫星过顶 · 卫导重算 · 目标点计分 · 胜负判定
```

一回合 = 1 小时。目标点由可占领单位控制，每回合结算胜负点；期满点数高者获胜。

## v1.2 新增机制（战术深度）

### 1. 战场天气与时段

- **时段**：拂晓 / 白天 / 黄昏 / 夜间，按作战日循环（默认 6 回合 = 1 个昼夜，
  一个 16–18 回合的想定可覆盖约 3 个昼夜）。
- **天候**：晴 / 雨 / 雾 / 雪，按想定种子确定性演进——同一想定每局完全一致，
  读档也能精确复现。

| | 光学 | 红外 | 雷达 |
|---|---|---|---|
| 白天·晴 | 1.00 | 0.92 | 1.00 |
| 夜间·晴 | **0.28** | **1.32** | 0.94 |
| 白天·雾 | 0.42 | 0.83 | **0.62** |
| 白天·雨 | 0.82 | 0.87 | 0.84 |

- 夜间光学几乎失效、**红外成为夜战主力**；雨雾大幅削弱雷达与光电。
- 电子侦察（ESM）、声呐与天基侦察**不受天候影响**——被动手段的价值凸显。
- AI 会据此调整：雨雾或夜间主动开机雷达补充态势，晴朗白天反而关机降低暴露。

### 2. 补给线与纵深

- 后勤枢纽有**覆盖半径**与**承载力**；部队在半径内即可获得补给，
  **不必站在枢纽上**。
- 承载力有限：深入敌后或枢纽被打瘫的部队会**断粮**——弹药无法补充、战损无法修复。
- 地图上用虚线显示补给线，断粮单位标红色叉号。

| 设施 | 半径 | 承载 |
|---|---|---|
| 后勤枢纽 | 10 格 | 12 |
| 指挥部 / 港口 | 6–7 格 | 6–8 |
| 机场 | 6 格 | 8 |

### 3. 指挥体系

- 层级：**连级**（普通作战单位）→ **营级**（指挥所、雷达站、电子战连）→ **旅级**（旅指挥所）。
- 上级可向**指挥半径内**的下级下达指令：

| 指令 | 效果 |
|---|---|
| **集中火力** | 下级优先攻击指定目标（AI 目标评分 ×2.2） |
| **固守** | 下级不再前出，只在原地附近择优机动 |
| **优先目标** | 下级优先打击某类目标（防空 / 雷达 / 指挥所 / 空中） |

- 指令**有期限**（2 回合），到期后下属恢复自主决策；指挥者阵亡则指令一并撤销。
- AI 指挥所会自主选择高价值目标（防空阵地与雷达优先）下达集中火力。

### 4. 多点防空协同

- 同一阵营的防空单元组成**一体化防空网**，火控通道**统一记账与分配**——
  不再是"各打各的"。
- 网按单发拦截概率**择优派工**：多发弹药同时来袭时，不会让每个单位都对着第一发猛打。
- 每个节点有明确**分工**：区域防空 / 要地防空 / 点防御 / 自卫拦截 / 末段硬杀伤。
- 交战面板的「对手视角」会显示对方防空网的分工构成与剩余通道数。

### 5. 火力准备

- 间瞄火力（火炮 / 火箭炮）可**预先射击**：登记射界并标定目标区域。
- 消耗 1.5 机动点，**要求该区域有情报**——没有情报就登记射界是盲打。
- 准备完成后（1 回合）对射界内目标射击获得 **命中 ×1.45、毁伤 ×1.30**。
- 射界有效期 2 回合，过期自动失效；地图上以实线/虚线圈区分准备状态。

### 6. 电子战频段对抗

- 干扰按**频段**分别生效，不再是单一乘数：

| 频段 | 影响 | 反制 |
|---|---|---|
| **雷达** | 压制雷达探测与雷达制导 | 关闭雷达（但失去态势） |
| **通信** | 切断数据链，信火一体退化为陈旧诸元 | 主动「链 断」 |
| **导航** | 压制卫星导航，精确制导弹药退化到惯导 | 改用非 GPS 制导弹药 |

- 武器库新增 4 个电子战单位：雷达干扰连 / 通信干扰连 / 导航压制连 / 宽带干扰站；
  原有两个电子战单位也获得频段配置。
- AI 会按目标特征选择最有价值的干扰频段（打雷达目标的单位压雷达频段，等等）。

## 存档与读档

- **F5** 快速保存到槽位 1，**F9** 快速读取，**F10** 打开系统菜单（5 个槽位 + 返回主菜单）。
- 存档是纯 JSON（`saves/slotN.json`），记录：想定路径、全部单位状态（位置/耐久/备弹/燃油/
  雷达开关/压制）、在飞弹药、地块归属与设施损毁、胜负点、日志尾部。
- 读档时从想定文件重建地形与兵种模板，再套用存档状态，因此**想定文件被修改后旧存档仍可加载**
  （仅地形以文件为准）。

## 操作

> 下列键位均可自定义：主菜单「设置」或游戏内「F10 → 设置」中逐条改绑定，
> 保存到用户目录的 `user_config.json`，重启后生效。

| 输入 | 功能 |
|---|---|

### 地图 / 想定：`data/maps/*.json`

```jsonc
{
  "id": "strait_shield",
  "name": "海峡屏障 · 2027",
  "description": "……",
  "size": [40, 40],
  "tile_km": 12,

  // 每行一个字符串，每字符一格。w水 c滩涂 p平原 f林地 h丘陵 m山地 u城区 d荒漠 s沼泽
  "terrain": ["wwwwccpppp...", "..."],

  // 可选。0-9 表示 0/300/600/.../2700 米；缺省时按地形给默认海拔
  "elevation": { "rows": ["001122...", "..."] },

  "facilities": [
    { "x": 6, "y": 11, "facility": "airbase", "owner": "BLUE", "hp": 120 }
  ],

  "objectives": [
    { "x": 21, "y": 20, "name": "中央锚地", "kind": "capture",
      "side": "NEUTRAL", "value": 5, "owner": "NEUTRAL" }
  ],

  "deployments": {
    "BLUE": [ { "template": "m1a2", "x": 9, "y": 18 }, ... ],
    "RED":  [ { "template": "t90m", "x": 30, "y": 20, "name": "近卫第 1 坦克连" }, ... ]
  }
}
```

字段说明：

- `facility`：`airbase` / `port` / `radar_site` / `depot` / `sam_site` / `hq` / `city` / `none`
- `facilities[].hp`：设施结构完整度上限（默认 100）
- `objectives[].kind`：`capture`（争夺）/ `hold`（固守）/ `destroy` / `survive`
- 部署可选 `altitude`：`low` / `med` / `high`（空中平台）
- 部署可选 `name`：覆盖显示名称

地图生成工具：`python tools/make_maps.py`（重新生成内置两张地图）。

### 武器库：`data/units/armory.json`

三段结构：`sensors`（传感器目录）、`weapons`（武器目录）、`units`（兵种模板）。
目录中的条目可被多个兵种用 `"ref": "id"` 复用，并可用 `ammo` 覆盖备弹量。

```jsonc
{
  "sensors": [
    { "id": "radar_a50", "kind": "radar", "range": 26, "strength": 1.45,
      "counter_stealth": 0.30, "note": "Shmel-M" }
  ],

  "weapons": [
    { "id": "sm3_iia", "name": "RIM-161 SM-3 Block IIA", "kind": "sam",
      "range_min": 1.5, "range_max": 8.0,
      "pk": 0.34, "damage": 46, "ammo": 1,
      "guidance": "radar_active", "targets": ["air", "space"],
      "speed": 9.0, "interceptable": false, "evasion": 0.0,
      "max_salvo": 1, "real_range_km": "大气层外拦截 2500 km" }
  ],

  "units": [
    { "id": "ddg_burke", "name": "阿利·伯克级驱逐舰", "short": "DDG",
      "class": "destroyer", "domain": "sea",
      "hp": 200, "mp": 5.0, "armor": 0.25, "stealth": 0.20, "evasion": 0.18,
      "sensors": ["radar_aegis", "sonar_hull", "esm_std"],
      "weapons": [ { "ref": "sm6", "ammo": 8 }, { "ref": "sm3_iia", "ammo": 1 } ],
      "interceptors": 6, "intercept_pk": 0.56, "can_capture": true, "cost": 720 }
  ]
}
```

关键字段：

| 字段 | 说明 |
|---|---|
| `domain` | `land` / `air` / `sea` / `sub` / `infra` / `space` |
| `class` | 决定地图上的矢量图标（`mbt` `ifv` `arty` `mlrs` `sam` `ew` `radar` `destroyer` `sub` `fighter` `bomber` `aew` `uav` `satellite` …） |
| `stealth` | 0–1，1 为完全隐身（显著压缩探测距离） |
| `evasion` | 0–1，降低被命中率，同时降低被拦截概率 |
| `interceptors` / `intercept_pk` | 每回合可拦截弹药数与单次成功率 |
| `jam_radius` / `jam_strength` | 电子干扰半径（格）与强度 |
| `amphibious` | 是否具备两栖投送（可越海） |
| `can_capture` | 能否占领目标点/设施 |
| `sortie_shots` | 每回合可发射次数（战机 2–3 次） |
| `datalink` | 是否具备协同交战数据链（缺省 true） |
| `decoy_charges` | 可释放的电子诱饵数量 |
| `entrench_bonus` | 掩体带来的额外防护 |
| `can_fortify` | 可主动构筑/修复野战工事（步兵默认开） |
| `fort_power` | 单次构筑提升的工事等级（工兵 2） |
| `is_infantry` | 步兵类目标（缺省按 `class` 推断） |
| `one_shot_kill` | 被命中即毁（缺省：空中平台为 true） |
| `ballistic` | 弹道飞行：末段难拦截，可被中段反导系统交战 |
| `midcourse` | 中段反导拦截弹（SM-3 / THAAD / 77N6） |
| `strategic` | 洲际弹：战术防空无效，只能中段反导 |

武器字段：

| 字段 | 说明 |
|---|---|
| `kind` | `gun` `artillery` `mlrs` `atgm` `sam` `aam` `asm` `land_attack` `arm` `torpedo` `bomb` |
| `guidance` | `optical` `ir` `radar_semi` `radar_active` `gps_ins` `anti_radiation` `laser` `wire` `sonar` |
| `targets` | 可打击的作战域数组（含 `space` 即可反卫星） |
| `speed` | 每回合飞行格数（决定飞行时间） |
| `min_detection` | 开火所需最低情报等级 |
| `evasion` | 突防能力，降低被拦截概率 |
| `hypersonic` | 高超音速标记（UI 特殊配色 + 极高突防） |
| `salvo` / `max_salvo` | 默认齐射发数 / 玩家可选齐射上限 |
| `vs_facility` | 能否打击机场、港口等固定设施（缺省按武器类型推断） |
| `asat` | 是否具备反卫星能力（缺省根据 `targets` 是否含 `space` 推断） |
| `real_range_km` | 现实射程，仅用于界面展示 |

> **尺度说明**：地图 1 格 = 12 km，但游戏内射程是**平衡后的抽象值**，与 `real_range_km`
> 记录的现实数据并非线性对应（否则 400 km 的 S-400 会覆盖整张地图）。这是有意为之的
> 可玩性折中，修改 `range_max` 即可调整平衡。

`.github/workflows/ci.yml` 包含三个作业：

## 设计取舍

1. **射程抽象化**。真实的 S-400（400 km）与坦克炮（3 km）相差两个数量级，任何单一比例尺
   都无法同时容纳。故采用平衡射程 + 现实射程对照展示。
2. **情报即门槛**。相比"堆数值"，本作把杀伤链前端（发现—识别—跟踪）做成硬约束，使预警机、
   电子战飞机、雷达站具备与其造价相称的战略价值。
3. **发射不等于命中**。远程弹药有飞行时间，途中受目标机动、情报中断、防空拦截三重影响。
4. **后勤是约束**。航空兵受燃油与基地制约，设施可被瘫痪——这使"打机场"成为与"打飞机"
   同等重要的作战选择。
5. **AI 对等受雾**。AI 使用与玩家完全相同的探测规则，不享受全图视野。

## 已知限制

- 卫星轨道为匀速直线地面轨迹，未建模轨道倾角、变轨与真实过顶几何；反卫星按常数距离交战；
- AI 为启发式规则，长局中可能出现局部僵持；
- 诱饵按频段区分，但未模拟同一诱饵在不同距离上的信号强度变化；
- 工事未区分堑壕/掩体/雷场的构筑时间差异；
- 中段反导只有一次窗口，未模拟多段拦截、动能杀伤与碎片效应；
- 烟幕为格子级遮蔽，未模拟随风扩散。

完整清单见 [`ROADMAP.md`](ROADMAP.md) 的「已知的机制边界」。

## 扩展建议

- 新增想定：用编辑器绘制后保存，或复制 `data/maps/*.json` 修改；`--check` 会校验合法性。
- 新增兵种：在 `data/units/armory.json` 的 `units` 中追加，`class` 决定图标，`notes` 显示在资料栏。
- 调整平衡：直接改 `pk` / `range_max` / `stealth` / `intercept_pk`，用 `--sim` 快速回归验证。
